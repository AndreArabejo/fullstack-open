# 0.6: New note in Single page app diagram

User creates a new note on the single-page version of the app.

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: JS adds the note to the screen right away
    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    Note right of browser: body is JSON {content, date}, header Content-Type: application/json
    server-->>browser: 201 created, no redirect
```
