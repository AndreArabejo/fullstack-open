# 0.4: New note diagram

User writes a note into the text field on https://studies.cs.helsinki.fi/exampleapp/notes and clicks Save.

```mermaid
sequenceDiagram
    participant browser
    participant server

    browser->>server : POST "sample note"
    server-->>browser : 302 redirect exampleapp/new_note
    browser->>server : GET exampleapp/notes
    server-->>browser : 200 + html file
    browser->>server : GET exampleapp/main.css
    server-->>browser : 200 + CSS file
    browser->>server : GET exampleapp/main.js
    server-->>browser: 200 + JS file
    browser->>server : GET exampleapp/data.json
    server-->>browser : 200 + [{"content": "note 1", "date": "date1"},{"content": "note 2", "date": "date2"}...]
```
